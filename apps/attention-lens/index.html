Attention Lens

Every token asks a question (query) and every token offers an answer (key). Type a sentence and see how four attention heads distribute weight, and how the choice of positional encoding changes the picture.

rows = query · columns = key · click a row label to inspect it
click a word to make it the query

How it works: each token gets an embedding built from hashed character n-grams, so repeated or similar words have similar vectors. Each head projects those embeddings with its own fixed random matrix and computes softmax(qkᵀ/√d). Heads are not trained, which keeps the effect of positional encoding easy to see in isolation. Everything runs locally in your browser.
